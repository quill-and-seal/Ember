# Feuille de route d'Ember

Chaque idée a son issue sur GitHub, avec ses détails et ses points à trancher. Une case cochée = idée réalisée.
Étiquettes : **prioritaire** marque les quatre idées jugées les plus utiles en partie.

## Déjà fait

- [x] Émetteurs posés sur la scène, presets, synchronisation (0.1.0)
- [x] Moteur maison pensé pour la vue du dessus (va0.1.0)
- [x] Vent de scène qui déplace les effets et change leur comportement (va0.1.0)
- [x] Flammes fragiles soufflées par le vent, bougie (va0.1.0)
- [x] Lumière adaptative, créée par Ember ou liée à une lumière de la scène (va0.1.0)
- [x] Moteur Ember par défaut dans la version stable, réactions au monde : murs, tokens, obscurité (0.2.0)
- [x] Groupes d'effets : plusieurs effets sous un seul émetteur, avec une seule lumière et une extinction partagée (0.3.0)
